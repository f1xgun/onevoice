# Проверка форм и состояний

Снимки получены из компонентов рабочей ветки, а не из работающего стенда.
API изолирован тестовыми ответами; имена аккаунтов, показатели использования и
остатки в этих снимках — тестовые данные. Снимки не подтверждают состояние
реального аккаунта или работоспособность внешних интеграций.

64 снимка: восемь поверхностей × ru/en × light/dark × 375/1440 px.

| Имя файла    | Проверяемая поверхность                                 |
| ------------ | ------------------------------------------------------- |
| login        | `/login`, включая публичную оболочку                    |
| profile      | `ProfileForm`, заполненная форма организации            |
| settings     | `/settings`, имя и пароль                               |
| integrations | `/integrations`, два аккаунта Telegram и Google preview |
| billing      | `/settings/billing`, тариф и использование              |
| connection   | `TelegramConnectModal`                                  |
| error        | `/integrations`, ошибка загрузки                        |
| empty        | `/integrations`, успешный пустой ответ                  |

CSS компилируется из текущих globals.css и Tailwind-конфигурации. Шрифты Golos
Text и JetBrains Mono берутся из файлов next/font локальной сборки. В браузере
проверяется фактическое отсутствие горизонтальной прокрутки через scrollTo и
scrollX, а не только scrollWidth.

Дополнительные браузерные тесты проверяют вход, чат и настройки при 320 px в
обеих локалях, показ ссылки обхода при Tab и переход фокуса в main. Проверки
диалогов включают Escape, focus trap, возврат фокуса, закрытие минимум 44×44 px,
прокрутку длинной формы и доступность действий при высоте окна 320/360 px.
Уменьшение окна моделирует ограниченную доступную область; оно не заменяет
проверку настоящей экранной клавиатуры iOS/Android.

Для повторного получения снимков сначала выполнить `pnpm build`, затем:

```sh
PATH=/Users/f1xgun/.nvm/versions/node/v20.20.2/bin:$PATH RUN_LAYOUT_TESTS=1 pnpm exec vitest run --maxWorkers=1 test-utils/forms-matrix.test.tsx
```
