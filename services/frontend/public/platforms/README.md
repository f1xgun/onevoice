# Platform marks

Local decorative SVGs; visible text in each consumer identifies the platform. No remote asset requests at runtime. Availability and connection status come from the API, independently of the mark.

Sources retrieved 2026-09-09:

- Telegram, VK, WhatsApp, Google, Instagram, Odnoklassniki: [Simple Icons](https://github.com/simple-icons/simple-icons), `icons/{name}.svg`, CC0. Paths unchanged, normalized to a monochrome fill.
- Yandex Business: [Tabler brand-yandex](https://github.com/tabler/tabler-icons/blob/main/icons/outline/brand-yandex.svg), MIT. Stroke normalized to monochrome. Represents the Yandex brand.
- 2GIS: [official header logo](https://info.2gis.ru/assets/header/logo-color-ru.svg); retained the colored symbol and cropped out the wordmark.
- Avito: [official Avito Tech site](https://www.avito.tech/), [source SVG](https://static.tildacdn.com/tild3739-3839-4164-a231-616561643434/Avito-Logo_1.svg); retained the four-circle symbol and cropped out the wordmark.

Platform names and marks belong to their respective owners. Unmapped demand-only channels use the generic globe icon.
