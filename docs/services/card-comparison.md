The business card shows only supported comparison fields: weekly Yandex hours; VK title, description and website; Telegram title and description. Missing or failed comparisons never establish a matching receipt. The sidebar names the checked fields. The preview uses recorded hours for the current weekday and applies a special-date override when present; it does not infer a live open/closed status without a business timezone.

`POST /businesses/{id}/integrations/restore-hours` requires business.update and the existing verified-email gate. It queues the existing schedule capability in the same bounded sync runner. Title, description, photo and general profile capabilities are not invoked. The response acknowledges queueing; the comparison remains authoritative for delivery.

`POST /businesses/{id}/integrations/adopt-hours` requires business.update and takes the displayed channel identifier and check timestamp. It accepts only a healthy, active, business-owned Yandex snapshot with all seven weekdays. The repository atomically saves the weekly schedule and clears its mismatch episode, preserving other settings, special dates, the remote snapshot, the original check time and the next-check time. A changed snapshot or an active reconciliation pass returns a conflict without a partial write. This path never queues or dispatches a platform update.
